# TuoTempo · Lavagna 1 — Le origini

Whiteboard animation per la presentazione del passato al ventennale TuoTempo (aperitivo del 2 dicembre 2026). Prima lavagna: le origini. È un lavoro in corso, non ancora la versione finale.

**Apri l'animazione:** [culetti.github.io/tuotempo-lavagna](https://culetti.github.io/tuotempo-lavagna/)

In alternativa, scarica `index.html` e aprilo in Chrome, Edge o Safari: è un file autonomo, non serve un server.

## Controlli

- **Spazio** o **clic**: avvia e continua. L'animazione si ferma sulle foto; da lì si riprende a braccio.
- **R**: ricomincia
- **I**: sottotitoli inglese / italiano (la voce resta in inglese)
- **F**: schermo intero
- **H**: mostra o nasconde i comandi

Formato 1920×1080 (16:9).
